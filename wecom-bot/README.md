# 家庭健康助手 · 企业微信 Bot

微信发一张血压计照片 → 自动识别血压/心率并记录；体检报告拍照 → 自动提取存档；发送「分析」→ AI 生成阶段性健康分析。

## 首次配置（约 20 分钟）

### 1. 注册企业微信，创建自建应用
1. 到 [work.weixin.qq.com](https://work.weixin.qq.com) 免费注册（可不认证，自建应用仅自己可见）。
2. 管理后台 → 应用管理 → 自建 → 创建应用，记下 **AgentId**。
3. 应用页 →「我的企业」页签下可查到 **CorpID**；应用详情里点「查看」拿到 **Secret**。
4. **开启微信插件**：「我的企业」→ 微信插件 → 邀请你的微信关注（用二维码）。之后在普通微信里就能直接给这个应用发消息。

### 2. 配置接收消息回调
1. 应用详情 → 接收消息 → 设置 API 接收。
2. URL 填 `https://你的公网域名/wecom/callback`（见下方内网穿透）。
3. Token 和 EncodingAESKey 随机生成，**复制保存**。
4. 数据格式选 **JSON**。

### 3. 内网穿透（家里 Windows 电脑没有公网 IP）
推荐任选其一：
- [cpolar](https://www.cpolar.com)：注册后一条命令 `cpolar http 8901`，得到临时 https 地址（免费版域名会变，变动后回企微后台改 URL 即可）。
- 有自己的域名/服务器时用 frp 更稳定。

### 4. 配置并启动
```bat
cd wecom-bot
pip install -r requirements.txt
copy .env.example .env   :: 然后编辑 .env 填入所有配置
python run.py
```

在企微后台「接收消息」页点保存 → 回调验证通过即部署成功。

## 日常使用（微信里直接发）
| 你发什么 | Bot 做什么 |
|---|---|
| 血压计照片 | 识别血压/心率，回复"已记录 第n/3次"，≥140/90 时提醒；心率漏读时自动用七段码识别兜底 |
| 体检报告照片 | 提取关键指标和结论存档 |
| `修正 血压138/85 心率76` | 改最近一条血压记录（可只改其中一项），本地和多维表格同步更新 |
| `修正 心率76` / `修正 时间7点50` | 单独补记心率 / 改测量时间 |
| `撤销` | 删除最近一条血压记录（多维表格同步删除） |
| `今日` / `本周` | 查看血压记录和均值 |
| `分析` | AI 分析近 30 天血压趋势 + 体检数据，生成建议 |
| `帮助` | 用法说明 |

照片识别错了不用去多维表格手动改，对话里发「修正 …」即可自我校验；每次修正都会回显修改前后的值和影响的记录时间。

数据存本地 `data/health.db`（SQLite），照片存 `data/images/`，全部在自己电脑上。
